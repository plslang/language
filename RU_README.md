# PLang — язык программирования от `kiwinatra` и других.

`Вам потребуется` C++ (17), g++ и, возможно, мозг?

## Структура

Папка `/compiler` является основной папкой для кода языка.

Она содержит *3* папки.

* compiler — содержит **основной код** языка для понимания его собственного синтаксиса
* lexer — содержит **инструкции** для парсинга языка
* parser — парсит **ваш код** в C++.
