# PLang - homemade language written by `kiwinatra` and others.

`Stack:` C++ (17), g++, and a bit of brain

## Structure

The `/compiler` folder is the main folder for code of the language.

It contains *3* folders.

* compiler - contains **main code** for the language to understand it own syntaxis
* lexer - contains **instruction** for language to parse
* parser - parses **your code** into C++.
